# Яндекс Дискысь ваньзэ кызьы поттыны

Каньыл валэктон. Вить минут ёрос дыр басьтоз.

*Ӟуч кылысь берыктэм — тупатонъёсты [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) пыр ыстэ ке, туж тау.*

**Мар луиз.** 2026 арын коньывуон толэзьлэн 11-тӥ нуналэз дырысен Яндекс Дисклэн сайтаз папкаез, кӧня ке файлэз яке вань Дискез огпол поттыны уг луы — одӥг-одӥгзэ гинэ. «Яндекс Дискысь ваньзэ поттыны» нимо дунтэм браузерлэн паськытэтэз «Поттыны» кнопкаез берыктэ: со файлъёсты одӥг-одӥгзэ ачиз поттэ но Дискын кадь ик папкаосы пуктэ.

**Мар кулэ:**

- компьютер яке ноутбук (Windows, macOS яке Linux);
- Google Chrome яке Яндекс Браузер (Edge, Opera, Brave, Vivaldi но яралозы);
- компьютерын буш инты — Дискын кӧня инты басьтэмын, сокем ёрос.

Телефонын уг ужа: мобильной браузеръёсы сыӵе паськытэтэз пуктыны уг луы. Компьютер кулэ.

## 1-тӥ вамыш. Паськытэтэз поттэ

1. Зудэ: **[yandex-disk-download-all.zip поттыны](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл «Загрузки» папкае утиськоз.
2. Сое архивысь поттэ:
   - **Windows:** файл вылэ шыр пал кнопкаен зудэ → «Извлечь все…» (ваньзэ поттыны) → «Извлечь»;
   - **macOS:** файл вылэ кык пол зудэ.
3. `yandex-disk-download-all` папка кылдоз. Сое со интые, кытын со уг люкеты, пуктэ, лыдпус понна «Документы» папкае. Собере эн быдтэ: браузер паськытэтэз та папкаысь басьтэ.

## 2-тӥ вамыш. Паськытэтэз браузере пуктэ

**Google Chrome**

1. Адрес чуре `chrome://extensions` гожтэ но Enter зудэ.
2. Вылӥ бур сэрегын **«Режим разработчика»** (лэсьтӥсьлэн режимез) вошъяськонэз ӝуажтэ.
3. Вылӥ палэс сэрегысь нырысетӥ кнопкае зудэ — **«Загрузить распакованное расширение»** (усьтэм паськытэтэз пыртыны).
4. `yandex-disk-download-all` папкаез быръе (пушказ `manifest.json` файл кыллись папкаез).
5. Списокын «Скачать всё с Яндекс Диска» паськытэт кылдоз. Дась.

**Яндекс Браузер** — озьы ик, адресэз гинэ `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — адресъёс `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, собере озьы ик: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — та огшоры луэ: лавкаысь ӧвӧл паськытэтъёс озьы пуктӥсько. Паськытэт дунтэм, солэн кодэз усьтэм. Браузер кутскыкуз сыӵе паськытэтъёсты кыстыны куриське ке — эн сётэ.

## 3-тӥ вамыш. «Кытчы утьыны» юанэз кысэ

Озьы ӧвӧл ке браузер котькуд файл сярысь юалоз, нош соос сюрсъёсын луыны быгато.

- **Chrome:** `chrome://settings/downloads` усьтэ но **«Всегда указывать место для скачивания»** (котьку утьымон интыез юаны) шуэмез кысэ.
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → **«Всегда спрашивать, куда сохранять файлы»** пусэз ӵушылэ.
- **Мукет браузеръёс:** тупатонъёслэн поттонъёс люкетаз котькуд файлэз кытчы утьыны сярысь юанэз кысэ.

## 4-тӥ вамыш. Файлъёсты поттэ

1. [disk.yandex.ru](https://disk.yandex.ru) усьтэ но аслэсьтыд аккаунтад пыре. Диск вожвыл ик усьтэмын вал ке — бамез выльдэ (F5).
2. Улӥ бур сэрегын лыз **«Вань Дискез поттыны»** кнопка кылдоз. Папка пушкын солэн нимыз «Папкаез поттыны», нош файлъёсты пусъяды ке — «Пусъямзэ поттыны».
3. Солы зудэ. Укно усьтӥськоз:
   - **«Мае поттыны»** — вань Диск, та папка, пусъямез яке списокысь «Файлъёсты но папкаосты быръяны…»;
   - **«Кыӵе файлъёс»** — ваньзэ яке «Кулэ типъёс гинэ» (лыдпус понна, фотоос но видео гинэ);
   - **«Кытчы утьыны»** — компьютере Дискын кадь файлъёсын, одӥг ZIP-архивен яке мукет пилеме.
4. **«Поттонэз кутскыны»** зудэ но витьы. Укноын адӟиське, кӧня поттэмын ини.

![Паськытэтлэн укноез](../docs/setup.png)

*Суредын — ӟуч интерфейс. Кыл укнолэн вылӥ чураз быръяське: 23 кыл вань, удмурт кыл но.*

**Поттон мынон дырын** Дисклэсь вкладказэ пичиятыны луэ, нош сое **эн пытсалэ**. Вкладка пытсаськиз яке компьютер кысӥз ке — Дискез выльысь усьтэ но «Азьланьтыны» зудэ. Поттэм файлъёс выльысь уг поттӥсько.

**Файлъёс кытын:** «Загрузки» → «Яндекс Диск», Дискын кадь папкаосъя.

## Мар ке уг пот ке

| Мар адӟиське | Мар кароно |
| --- | --- |
| Лыз кнопка ӧвӧл | Дисклэсь бамзэ выльдэ (F5). `chrome://extensions` пушкын паськытэт ӝуажтэмын-а, эскере. |
| Браузер котькуд файлэз кытчы утьыны юа | 3-тӥ вамышез лэсьтэ но «Азьланьтыны» зудэ. |
| Куд-ог файлъёс «Уг пот» | Яндекслэн серверъёсыз али ваньзэ уг сёто. Одӥг-кык час бере «Потымтэосты нош ӧдъяны» зудэ. Сыӵе файлъёслэсь списоксэс «Отчёт (CSV)» кнопка утьыны луэ. |
| Компьютерын инты ичи | Люкетъёсын «ZIP-архив», пилеме выжтон яке браузерлэн тупатонъёсаз палэнысь дискез поттонъёслэн папказыя быръе. |
| «Яндекс эскеронэз ортчытыны куриське» | «Эскеронэз ортчытыны» зудэ, робот ӧвӧл шуыса юнматэ, собере «Азьланьтыны» зудэ. |
| Фотолэн нимаз «(азьвыл учкон)» вань | Оригиналзэ ӧз сётэ, пичиятэм копиез утемын. Берлогес «Азьвыл учкон интые оригиналъёсты нош ӧдъяны» зудэ. |

## Та кышкытэн ӧвӧл-а?

- Паськытэт Яндекс Дисклэн сайтаз гинэ но тӥляд браузерады гинэ ужа. Яндекслэсь паролез уг юа. Тӥляд файлъёсты нокытчы но уг ысто — ас огазеям пилемлэсь кожмысь.
- Та Яндекслэн программаез ӧвӧл, нош кодэз усьтэм асэрказ дунтэм проект.

## Кызьы быдтыны яке выльдыны

- **Быдтыны:** `chrome://extensions` → паськытэт котыръяз «Удалить». Поттэм файлъёс кылёзы.
- **Выльдыны:** архивез выльысь поттэ (1-тӥ вамыш), вуж папка вылтӥ файлъёсты вошъяса поттэ, собере `chrome://extensions` пушкын паськытэт котырысь котырес стрелкае зудэ.
