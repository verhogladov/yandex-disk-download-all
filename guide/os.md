# Яндекс Дискӕй иууылдӕр куыд ӕрбаисын

Хуымӕтӕг амынд. Иу фондз минуты ахӕсдзӕн.

*Уырыссаг ӕвзагӕй тӕлмац — раст кӕнӕнтӕ [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues)-ы руаджы куы ӕрвитат, уӕд бузныг уыдзыстӕм.*

**Цы ӕрцыд.** 2026 азы 11 октябрӕй фӕстӕмӕ Яндекс Дискы сайты папкӕ, цалдӕр файлы кӕнӕ ӕнӕхъӕн Диск иуцъусӕй ӕрбаисӕн нал ис — ӕрмӕст иугай. «Яндекс Дискӕй иууылдӕр ӕрбаисын» зӕгъгӕ ӕнӕмыздӕг браузеры уӕрӕхгӕнӕн «Ӕрбаисын» ӕркъуыры фӕстӕмӕ раздахы: файлтӕ иугай йӕхӕдӕг ӕрбаисы ӕмӕ сӕ Дискы куыд сты, ахӕм папкӕтӕм авӕры.

**Цы хъӕуы:**

- компьютер кӕнӕ ноутбук (Windows, macOS кӕнӕ Linux);
- Google Chrome кӕнӕ Яндекс Браузер (Edge, Opera, Brave, Vivaldi дӕр бӕззынц);
- компьютеры сӕрибар бынат — Дискы цас бынат ахсы, уыйас.

Телефоны нӕ кусы: мобилон браузертӕм ахӕм уӕрӕхгӕнӕн сӕвӕрӕн нӕй. Компьютер хъӕуы.

## 1-аг къахдзӕф. Уӕрӕхгӕнӕн ӕрбаисут

1. Ӕлхъивут: **[yandex-disk-download-all.zip ӕрбаисын](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл бахъахъхъӕндзӕн «Загрузки» папкӕйы.
2. Йӕ архивӕй систут:
   - **Windows:** файлыл мышкӕйы рахиз ӕркъуырӕй ӕлхъивут → «Извлечь все…» (иууылдӕр сисын) → «Извлечь»;
   - **macOS:** файлыл дыууӕ хатты ӕлхъивут.
3. Фӕзындзӕн `yandex-disk-download-all` папкӕ. Йӕ ахӕм ранмӕ бахӕссут, кӕм никӕмӕн хъыгдардзӕн, зӕгъӕм «Документы» папкӕмӕ. Фӕстӕдӕр ӕй ма аппарут: браузер уӕрӕхгӕнӕн ацы папкӕйӕ исы.

## 2-аг къахдзӕф. Уӕрӕхгӕнӕн браузеры сӕвӕрут

**Google Chrome**

1. Адресы рӕнхъы ныффыссут `chrome://extensions` ӕмӕ ӕлхъивут Enter.
2. Уӕллаг рахиз къуымы ссудзут **«Режим разработчика»** (арӕзтгӕнӕджы режим) рахизгӕнӕн.
3. Уӕллаг галиу къуымы фыццаг ӕркъуырыл ӕлхъивут — **«Загрузить распакованное расширение»** (байгом уӕрӕхгӕнӕн ӕрбавгӕнын).
4. Равзарут `yandex-disk-download-all` папкӕ (йӕ мидӕг `manifest.json` файл кӕмӕн ис, уыцы папкӕ).
5. Номхыгъды фӕзындзӕн «Скачать всё с Яндекс Диска» уӕрӕхгӕнӕн. Цӕттӕ у.

**Яндекс Браузер** — афтӕ, ӕрмӕст адрес у `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — адрестӕ `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, уый фӕстӕ афтӕ: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — уый ӕнӕхъӕнӕй ӕмбӕлгӕ у: туыгӕнӕй чи нӕ у, ахӕм уӕрӕхгӕнӕнтӕ афтӕ ӕвӕрынц. Уӕрӕхгӕнӕн ӕнӕмыздӕг у, йӕ код — байгом. Браузер райдайгӕйӕ ахӕм уӕрӕхгӕнӕнтӕ ахуыссын куы бафӕрса — ма сразы ут.

## 3-аг къахдзӕф. «Кӕм бахъахъхъӕнын» фарст ахуыссут

Уӕдӕ браузер алы файлӕй дӕр фӕрсдзӕн, уыдон та минтӕй уӕвын сӕ бон у.

- **Chrome:** байгом кӕнут `chrome://settings/downloads` ӕмӕ ахуыссут **«Всегда указывать место для скачивания»** (алкуыдӕр бахъахъхъӕнӕн бынат фӕрсын).
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → систут **«Всегда спрашивать, куда сохранять файлы»** нысан.
- **Ӕндӕр браузертӕ:** уагӕвӕрдты ӕрбаисыны хайы ахуыссут алы файл кӕм бахъахъхъӕнын, уыцы фарст.

## 4-ӕм къахдзӕф. Файлтӕ ӕрбаисут

1. Байгом кӕнут [disk.yandex.ru](https://disk.yandex.ru) ӕмӕ бацӕут уӕ аккаунтмӕ. Диск раздӕр байгом куы уыд — фарс ног кӕнут (F5).
2. Дӕллаг рахиз къуымы фӕзындзӕн ӕрвхуыз **«Ӕнӕхъӕн Диск ӕрбаисын»** ӕркъуыр. Папкӕйы мидӕг йӕ ном у «Папкӕ ӕрбаисын», файлтӕ куы нысан кӕнат — «Нысангонд ӕрбаисын».
3. Йӕ ӕлхъивут. Байгом уыдзӕн рудзынг:
   - **«Цы ӕрбаисын»** — ӕнӕхъӕн Диск, ацы папкӕ, нысангонд кӕнӕ номхыгъдӕй «Файлтӕ ӕмӕ папкӕтӕ равзарын…»;
   - **«Цавӕр файлтӕ»** — иууылдӕр кӕнӕ «Ӕрмӕст хъӕугӕ хуызтӕ» (зӕгъӕм, ӕрмӕст къамтӕ ӕмӕ видео);
   - **«Кӕм бахъахъхъӕнын»** — компьютермӕ файлтӕй, Дискы куыд сты, афтӕ, иу ZIP-архивӕй кӕнӕ ӕндӕр мигъмӕ.
4. Ӕлхъивут **«Ӕрбаисын райдайын»** ӕмӕ ӕнхъӕлмӕ кӕсут. Рудзынджы зыны, цас ӕрбаист ис.

![Уӕрӕхгӕнӕны рудзынг](../docs/setup.png)

*Нывы — уырыссаг интерфейс. Ӕвзаг рудзынджы уӕллаг рӕнхъы равзарын ис: 23 ӕвзаджы ис, ирон дӕр.*

**Ӕрбаисын цӕугӕйӕ** Дискы вкладкӕ стъӕлфӕн у, фӕлӕ йӕ **ма сӕхгӕнут**. Вкладкӕ куы ӕхгӕд ӕрцӕуа кӕнӕ компьютер куы ахуысса — Диск ногӕй байгом кӕнут ӕмӕ ӕлхъивут «Дарддӕр». Ӕрбаист файлтӕ ногӕй нӕ ӕрбаисынц.

**Файлтӕ кӕм сты:** «Загрузки» → «Яндекс Диск», Дискы цы папкӕтӕ ис, уыдоны.

## Исты куы нӕ рауайа

| Цы зыны | Цы кӕнын хъӕуы |
| --- | --- |
| Ӕрвхуыз ӕркъуыр нӕй | Дискы фарс ног кӕнут (F5). `chrome://extensions`-ы бакӕсут, уӕрӕхгӕнӕн ссыгъд у ӕви нӕ. |
| Браузер алы файлӕй дӕр фӕрсы, кӕм ӕй бахъахъхъӕна | Сӕххӕст кӕнут 3-аг къахдзӕф ӕмӕ ӕлхъивут «Дарддӕр». |
| Иуӕй-иу файлтыл ис «Нӕ рауад» | Яндексы серверты ныр иууылдӕр нӕ дӕттынц. Иу-дыууӕ сахаты фӕстӕ ӕлхъивут «Нӕ рауадыстысты, уыдон ногӕй». Ахӕм файлты номхыгъд бахъахъхъӕны «Отчет (CSV)» ӕркъуыр. |
| Компьютеры бынат гыццыл ис | Равзарут хӕйттӕй «ZIP-архив», мигъмӕ хӕссын кӕнӕ браузеры уагӕвӕрдты ӕддаг диск ӕрбаисыны папкӕйы хуызы. |
| «Яндекс курӕг у бӕрӕггӕнӕн ацӕуыныл» | Ӕлхъивут «Бӕрӕггӕнӕн ацӕуын», бафидар кӕнут, робот кӕй нӕ стут, уый, стӕй ӕлхъивут «Дарддӕр». |
| Къамы номы ис «(разӕркаст)» | Оригинал нӕ радтой, бахъахъхъӕд ӕрцыд гыццылгонд къопи. Фӕстӕдӕр ӕлхъивут «Разӕркасты бӕсты оригиналтӕ ногӕй бафӕлварын». |

## Ай тӕссаг нӕу?

- Уӕрӕхгӕнӕн кусы ӕрмӕст Яндекс Дискы сайты ӕмӕ ӕрмӕст уӕ браузеры. Яндексы пароль нӕ фӕрсы. Уӕ файлтӕ никуыдӕм ӕрвыст цӕуынц — сымах кӕцы мигъ бафтауат, уымӕй уӕлдай.
- Ай Яндексы программӕ нӕу, фӕлӕ байгом кодимӕ сӕрибар ӕнӕмыздӕг проект.

## Куыд ӕй аппарын кӕнӕ ног кӕнын

- **Аппарын:** `chrome://extensions` → уӕрӕхгӕнӕны фарсмӕ «Удалить». Ӕрбаист файлтӕ баззайдзысты.
- **Ног кӕнын:** архив ногӕй ӕрбаисут (1-аг къахдзӕф), зӕронд папкӕйы сӕрты йӕ систут файлтӕ ивгӕйӕ, стӕй `chrome://extensions`-ы ӕлхъивут уӕрӕхгӕнӕны фарсмӕ тымбыл фатыл.
