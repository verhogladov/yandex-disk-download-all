# Яндекс Дисктан бөтәһен дә нисек күсереп алырға

Ябай күрһәтмә. Яҡынса биш минут ваҡыт ала.

*Рус теленән тәржемә — төҙәтмәләрҙе [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) аша ебәрһәгеҙ, рәхмәтле булырбыҙ.*

**Ни булды.** 2026 йылдың 11 октябренән Яндекс Диск сайтында папканы, бер нисә файлды йәки бөтә Дискты бер юлы күсереп алып булмай — бары берәмләп кенә. «Яндекс Дисктан бөтәһен дә күсереп алыу» тигән бушлай браузер киңәйтмәһе «Күсереп алыу» төймәһен кире ҡайтара: ул файлдарҙы берәмләп үҙе күсерә һәм Дисктағы кеүек папкаларға урынлаштыра.

**Ни кәрәк:**

- компьютер йәки ноутбук (Windows, macOS йәки Linux);
- Google Chrome йәки Яндекс Браузер (Edge, Opera, Brave, Vivaldi ла яраҡлы);
- компьютерҙа буш урын — яҡынса Дискта күпме урын алынған, шул саҡлы.

Телефонда эшләмәй: мобиль браузерҙарға бындай киңәйтмә ҡуйып булмай. Компьютер кәрәк.

## 1-се аҙым. Киңәйтмәне күсереп алығыҙ

1. Баҫығыҙ: **[yandex-disk-download-all.zip күсереп алыу](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл «Загрузки» папкаһына һаҡланасаҡ.
2. Уны архивтан сығарығыҙ:
   - **Windows:** сысҡандың уң төймәһе менән файлға баҫығыҙ → «Извлечь все…» (бөтәһен дә сығарыу) → «Извлечь»;
   - **macOS:** файлға ике тапҡыр баҫығыҙ.
3. `yandex-disk-download-all` папкаһы барлыҡҡа килә. Уны ҡамасауламаҫлыҡ урынға, мәҫәлән «Документы» папкаһына күсерегеҙ. Һуңынан юймағыҙ: браузер киңәйтмәне ошо папканан ала.

## 2-се аҙым. Киңәйтмәне браузерға ҡуйығыҙ

**Google Chrome**

1. Адрес юлына `chrome://extensions` яҙығыҙ һәм Enter баҫығыҙ.
2. Өҫкө уң мөйөштә **«Режим разработчика»** (эшләүсе режимы) күсергесен ҡабыҙығыҙ.
3. Өҫкө һул мөйөштәге беренсе төймәгә баҫығыҙ — **«Загрузить распакованное расширение»** (асылған киңәйтмәне йөкләү).
4. `yandex-disk-download-all` папкаһын һайлағыҙ (эсендә `manifest.json` файлы булған папка).
5. Исемлектә «Скачать всё с Яндекс Диска» киңәйтмәһе барлыҡҡа килә. Әҙер.

**Яндекс Браузер** — нәҡ шулай уҡ, адресы ғына `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — адрестар `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, артабан нәҡ шулай уҡ: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — был ғәҙәти хәл: магазиндан булмаған киңәйтмәләр шулай ҡуйыла. Киңәйтмә бушлай, уның коды асыҡ. Әгәр браузер эшләй башлағанда бындай киңәйтмәләрҙе һүндерергә тәҡдим итһә — баш тартығыҙ.

## 3-сө аҙым. «Ҡайҙа һаҡларға» һорауын һүндерегеҙ

Юғиһә браузер һәр файл тураһында һораясаҡ, ә улар меңәрләгән булырға мөмкин.

- **Chrome:** `chrome://settings/downloads` асығыҙ һәм **«Всегда указывать место для скачивания»** (һәр ваҡыт һаҡлау урынын һорау) тигәнде һүндерегеҙ.
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → **«Всегда спрашивать, куда сохранять файлы»** билдәһен алығыҙ.
- **Башҡа браузерҙар:** көйләүҙәрҙең күсереүҙәр бүлегендә һәр файлды ҡайҙа һаҡлау тураһындағы һорауҙы һүндерегеҙ.

## 4-се аҙым. Файлдарҙы күсереп алығыҙ

1. [disk.yandex.ru](https://disk.yandex.ru) асығыҙ һәм аккаунтығыҙға инегеҙ. Диск инде асыҡ булһа — битте яңыртығыҙ (F5).
2. Аҫҡы уң мөйөштә зәңгәр **«Бөтә Дискты күсереп алыу»** төймәһе барлыҡҡа килә. Папка эсендә ул «Папканы күсереп алыу» тип атала, ә файлдарҙы билдәләһәгеҙ — «Билдәләнгәнде күсереп алыу».
3. Уға баҫығыҙ. Тәҙрә асыла:
   - **«Нимәне күсереп алырға»** — бөтә Диск, ошо папка, билдәләнгәндәр йәки исемлектән «Файлдарҙы һәм папкаларҙы һайлау…»;
   - **«Ниндәй файлдар»** — бөтәһе лә йәки «Кәрәкле төрҙәр генә» (мәҫәлән, фото һәм видео ғына);
   - **«Ҡайҙа һаҡларға»** — компьютерға Дисктағы кеүек файлдар итеп, бер ZIP-архив итеп йәки башҡа болотҡа.
4. **«Күсереүҙе башлау»** төймәһенә баҫығыҙ һәм көтөгөҙ. Тәҙрәлә күпмеһе күсерелгәне күренә.

![Киңәйтмә тәҙрәһе](../docs/setup.png)

*Һүрәттә — рус телендәге интерфейс. Тел тәҙрәнең өҫкө юлында һайлана: 23 тел бар, башҡортса ла бар.*

**Күсереү барғанда** Диск ҡыҫтырмаһын йыйып ҡуйырға була, ләкин уны **япмағыҙ**. Ҡыҫтырма ябылһа йәки компьютер һүнһә — Дискты яңынан асығыҙ һәм «Дауам итеү» төймәһенә баҫығыҙ. Инде күсерелгән файлдар ҡабат күсерелмәй.

**Файлдар ҡайҙа:** «Загрузки» → «Яндекс Диск», Дисктағы кеүек папкалар буйынса.

## Берәй нәмә килеп сыҡмаһа

| Ни күренә | Ни эшләргә |
| --- | --- |
| Зәңгәр төймә юҡ | Диск битен яңыртығыҙ (F5). `chrome://extensions` эсендә киңәйтмә ҡабыҙылғанын тикшерегеҙ. |
| Браузер һәр файлды ҡайҙа һаҡларға икәнен һорай | 3-сө аҙымды үтәгеҙ һәм «Дауам итеү» баҫығыҙ. |
| Ҡайһы бер файлдар «Килеп сыҡманы» | Яндекс серверҙары хәҙер бөтәһен дә бирмәй. Бер-ике сәғәттән «Килеп сыҡмағандарҙы ҡабатлау» баҫығыҙ. Бындай файлдар исемлеген «Хисап (CSV)» төймәһе һаҡлай. |
| Компьютерҙа урын аҙ | Өлөштәргә бүленгән «ZIP-архив», болотҡа күсереү йәки браузер көйләүҙәрендә тышҡы дискты күсереүҙәр папкаһы итеп һайлағыҙ. |
| «Яндекс тикшереүҙе үтеүҙе һорай» | «Тикшереүҙе үтеү» баҫығыҙ, робот түгеллегегеҙҙе раҫлағыҙ, шунан «Дауам итеү» баҫығыҙ. |
| Фото исемендә «(алдан ҡарау)» бар | Төп нөсхә бирелмәне, бәләкәйләтелгән күсермәһе һаҡланды. Һуңыраҡ «Алдан ҡарау урынына төп нөсхәләрҙе ҡабат тырышып ҡарау» баҫығыҙ. |

## Был хәүефһеҙме?

- Киңәйтмә Яндекс Диск сайтында ғына һәм һеҙҙең браузерҙа ғына эшләй. Яндекс серһүҙен һорамай. Файлдарығыҙ бер ҡайҙа ла ебәрелмәй — үҙегеҙ тоташтырған болоттан тыш.
- Был Яндекс программаһы түгел, ә коды асыҡ бойондороҡһоҙ бушлай проект.

## Нисек юйырға йәки яңыртырға

- **Юйыу:** `chrome://extensions` → киңәйтмә янындағы «Удалить». Күсерелгән файлдар ҡала.
- **Яңыртыу:** архивты яңынан күсереп алығыҙ (1-се аҙым), иҫке папка өҫтөнә файлдарҙы алмаштырып сығарығыҙ, шунан `chrome://extensions` эсендә киңәйтмә янындағы түңәрәк уҡҡа баҫығыҙ.
