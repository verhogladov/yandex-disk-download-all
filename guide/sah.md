# Яндекс Дискттан барытын хайдах хачайдыахха

Судургу ыйынньык. Биэс мүнүүтэ кэриҥэ бириэмэни ылар.

*Нуучча тылыттан тылбаас — көннөрүүлэри [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) нөҥүө ыытар буоллаххытына, махтанабыт.*

**Тугу буолла.** 2026 сыл алтынньы 11 күнүттэн Яндекс Диск сайытыгар паапканы, хас да билэни эбэтэр бүтүн Дискы биир кэмҥэ хачайдыыр кыах суох — биирдии эрэ. «Яндекс Дискттан барытын хачайдаа» диэн босхо браузер кэҥэтиитэ «Хачайдаа» тимэҕи төннөрөр: кини билэлэри биирдии бэйэтэ хачайдыыр уонна Дискка баарын курдук паапкаларга угар.

**Туох наада:**

- компьютер эбэтэр ноутбук (Windows, macOS эбэтэр Linux);
- Google Chrome эбэтэр Яндекс Браузер (Edge, Opera, Brave, Vivaldi эмиэ сөп);
- компьютерга кураанах миэстэ — Дискка төһө миэстэ ылыллыбытынан.

Төлөпүөҥҥэ үлэлээбэт: мобильнай браузердарга маннык кэҥэтиини туруорар кыах суох. Компьютер наада.

## 1-кы хардыы. Кэҥэтиини хачайдааҥ

1. Баттааҥ: **[yandex-disk-download-all.zip хачайдаа](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Билэ «Загрузки» паапкаҕа харалла сытыа.
2. Архыыптан таһаарыҥ:
   - **Windows:** билэ үрдүнэн мышь уҥа тимэҕинэн баттааҥ → «Извлечь все…» (барытын таһаар) → «Извлечь»;
   - **macOS:** билэни икки төгүл баттааҥ.
3. `yandex-disk-download-all` паапка үөскүөҕэ. Кинини мэһэйдээбэт сиргэ, холобур «Документы» паапкаҕа көһөрүҥ. Кэлин сотумаҥ: браузер кэҥэтиини бу паапкаттан ылар.

## 2-с хардыы. Кэҥэтиини браузерга туруоруҥ

**Google Chrome**

1. Аадырыс устуруокатыгар `chrome://extensions` суруйуҥ уонна Enter баттааҥ.
2. Үөһээ уҥа муннукка **«Режим разработчика»** (оҥорооччу режимэ) переключателы холбооҥ.
3. Үөһээ хаҥас муннуктааҕы бастакы тимэҕи баттааҥ — **«Загрузить распакованное расширение»** (арыллыбыт кэҥэтиини киллэр).
4. `yandex-disk-download-all` паапканы талыҥ (иһигэр `manifest.json` билэ сытар паапканы).
5. Испииһэккэ «Скачать всё с Яндекс Диска» кэҥэтии көстүө. Бэлэм.

**Яндекс Браузер** — олус маннык, аадырыһа эрэ `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — аадырыстар `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, салгыы олус маннык: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — бу үгэс быһыы: маҕаһыынтан буолбатах кэҥэтиилэр итинник туруоруллаллар. Кэҥэтии босхо, кода аһаҕас. Браузер саҕаланарыгар маннык кэҥэтиилэри араарарга этии киллэрдэҕинэ — аккаастаныҥ.

## 3-с хардыы. «Ханна харайыахха» диэн ыйытыыны араарыҥ

Оччоҕо суох браузер хас биирдии билэ туһунан ыйытыа, оттон кинилэр тыһыынчалыы буолуохтарын сөп.

- **Chrome:** `chrome://settings/downloads` арыйыҥ уонна **«Всегда указывать место для скачивания»** (куруук харайар миэстэни ыйыт) диэни араарыҥ.
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → **«Всегда спрашивать, куда сохранять файлы»** бэлиэни устуҥ.
- **Атын браузердар:** туруоруулар хачайдааһын салаатыгар хас биирдии билэни ханна харайар туһунан ыйытыыны араарыҥ.

## 4-с хардыы. Билэлэри хачайдааҥ

1. [disk.yandex.ru](https://disk.yandex.ru) арыйыҥ уонна аккаунтаҕытыгар киириҥ. Диск урут аһаҕас буоллаҕына — сирэйи саҥардыҥ (F5).
2. Аллара уҥа муннукка күөх **«Бүтүн Дискы хачайдаа»** тимэх көстүө. Паапка иһигэр кини «Паапканы хачайдаа» диэн ааттанар, оттон билэлэри бэлиэтээтэххитинэ — «Бэлиэтэммити хачайдаа».
3. Кинини баттааҥ. Түннүк арыллыа:
   - **«Тугу хачайдыахха»** — бүтүн Диск, бу паапка, бэлиэтэммит эбэтэр испииһэктэн «Билэлэри уонна паапкалары тал…»;
   - **«Ханнык билэлэр»** — барыта эбэтэр «Наадалаах көрүҥнэр эрэ» (холобур, хаартыска уонна видео эрэ);
   - **«Ханна харайыахха»** — компьютерга Дискка баарын курдук билэлэринэн, биир ZIP-архыыбынан эбэтэр атын былыкка.
4. **«Хачайдааһыны саҕалаа»** тимэҕи баттааҥ уонна кэтэһиҥ. Түннүккэ төһө хачайдамматын көрүөххүт.

![Кэҥэтии түннүгэ](../docs/setup.png)

*Ойууга — нууччалыы интерфейс. Тыл түннүк үөһээ устуруокатыгар талыллар: 23 тыл баар, сахалыы эмиэ.*

**Хачайдааһын бара турдаҕына** Диск вкладкатын кыччатыахха сөп, ол гынан баран кинини **сабымаҥ**. Вкладка сабылыннаҕына эбэтэр компьютер араҕыстаҕына — Дискы хаттаан арыйыҥ уонна «Салгыы» тимэҕи баттааҥ. Хачайдаммыт билэлэр хаттаан хачайдамматтар.

**Билэлэр ханна баалларый:** «Загрузки» → «Яндекс Диск», Дискка баар паапкаларынан.

## Туох эмэ табыллыбатаҕына

| Туох көстөр | Тугу гыныахха |
| --- | --- |
| Күөх тимэх суох | Диск сирэйин саҥардыҥ (F5). `chrome://extensions` иһигэр кэҥэтии холбоммутун бэрэбиэркэлээҥ. |
| Браузер хас биирдии билэни ханна харайары ыйытар | 3-с хардыыны толоруҥ уонна «Салгыы» баттааҥ. |
| Сорох билэлэр «Табыллыбата» | Яндекс сиэрбэрдэрэ билигин барытын биэрбэттэр. Биир-икки чаас буолан баран «Табыллыбатахтары хатылаа» баттааҥ. Маннык билэлэр испииһэктэрин «Отчуот (CSV)» тимэх харайар. |
| Компьютерга миэстэ аҕыйах | Чаастарга араарыллыбыт «ZIP-архыыбы», былыкка көһөрүүнү эбэтэр браузер туруорууларыгар таһаҕы дискы хачайдааһын паапкатынан талыҥ. |
| «Яндекс бэрэбиэркэни ааһары көрдөһөр» | «Бэрэбиэркэни аас» баттааҥ, робот буолбатаххытын бигэргэтиҥ, онтон «Салгыы» баттааҥ. |
| Хаартыска аатыгар «(иннинэн көрүү)» баар | Оригинал бэриллибэтэх, кыччатыллыбыт копията харалынна. Кэлин «Иннинэн көрүү оннугар оригиналлары хат холоон көр» баттааҥ. |

## Бу куттала суох дуо?

- Кэҥэтии Яндекс Диск сайытыгар эрэ уонна эһиги браузергытыгар эрэ үлэлиир. Яндекс киирии тылын ыйыппат. Билэлэргит ханна да ыытыллыбаттар — бэйэҕит холбообут былыккытыттан ураты.
- Бу Яндекс бырагырааммата буолбатах, кода аһаҕас тус бэйэтинэн босхо бырайыак.

## Хайдах сотуохха эбэтэр саҥардыахха

- **Сотуу:** `chrome://extensions` → кэҥэтии аттыгар «Удалить». Хачайдаммыт билэлэр хаалаллар.
- **Саҥардыы:** архыыбы хаттаан хачайдааҥ (1-кы хардыы), эргэ паапка үрдүнэн билэлэри солбуйан таһаарыҥ, онтон `chrome://extensions` иһигэр кэҥэтии аттынааҕы төгүрүк ох баттааҥ.
