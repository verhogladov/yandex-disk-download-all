# Яндекс Дискһээ бүгэдыень яажа буулгаха бэ

Хүнгэн заабари. Табан минута шахуу саг абана.

*Ородой хэлэнһээ оршуулга — заһабаринуудые [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) дээрэ эльгээбэл, баярлахабди.*

**Юун болооб.** 2026 оной октябриин 11-һээ хойшо Яндекс Дискын сайт дээрэ папка, хэдэн файл али бүхы Диск нэгэ доро буулгажа болохогүй — гансахан нэгэ нэгээрээ. «Яндекс Дискһээ бүгэдыень буулгаха» гэһэн түлбэригүй браузерай үргэдхэл «Буулгаха» товшуурые бусаана: тэрэнь файлнуудые нэгэ нэгээрээ өөрөө буулгажа, Диск дээрэ байһан шэнги папкануудта табина.

**Юун хэрэгтэйб:**

- компьютер али ноутбук (Windows, macOS али Linux);
- Google Chrome али Яндекс Браузер (Edge, Opera, Brave, Vivaldi мүн тохирхо);
- компьютер дээрэ сүлөө һуури — Диск дээрэ хэды һуури эзэлэгдэһэн, тэдыгээр.

Телефон дээрэ ажалладаггүй: мобильна браузернуудта иимэ үргэдхэл табижа болохогүй. Компьютер хэрэгтэй.

## 1-дэхи алхам. Үргэдхэлые буулгагты

1. Дарагты: **[yandex-disk-download-all.zip буулгаха](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл «Загрузки» папкада хадагалагдаха.
2. Архивһаа гаргагты:
   - **Windows:** файл дээрэ мышиин баруун товшуураар дарагты → «Извлечь все…» (бүгэдыень гаргаха) → «Извлечь»;
   - **macOS:** файл дээрэ хоёр дахин дарагты.
3. `yandex-disk-download-all` папка бии болохо. Тэрэниие һаад болохогүй газарта, жэшээлбэл «Документы» папка руу шэлжүүлэгты. Һүүлдэнь бү усадхагты: браузер үргэдхэлые энэ папкаһаа абадаг.

## 2-дохи алхам. Үргэдхэлые браузерта табигты

**Google Chrome**

1. Хаягай мүртэ `chrome://extensions` гэжэ бэшээд, Enter дарагты.
2. Дээдэ баруун булангта **«Режим разработчика»** (зохёогшын горим) һэлгүүрые ногоогты.
3. Дээдэ зүүн булангай түрүүшын товшуур дээрэ дарагты — **«Загрузить распакованное расширение»** (задалһан үргэдхэл ашаалха).
   ![«Режим разработчика» (1) болон «Загрузить распакованное расширение» (2) хаана байнаб](../docs/guide-extensions.png)
4. `yandex-disk-download-all` папка шэлэгты (соонь `manifest.json` файл байһан папка).
5. Жагсаалтада «Скачать всё с Яндекс Диска» үргэдхэл бии болохо. Бэлэн.

**Яндекс Браузер** — яг тиимэ, гансал хаягынь `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — хаягууд `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, саашань яг тиимэ: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — энэ ердын юумэн: дэлгүүрһээ бэшэ үргэдхэлнүүд иигэжэ табигдадаг. Үргэдхэл түлбэригүй, тэрэнэй код нээлттэй. Хэрбээ браузер эхилхэдээ иимэ үргэдхэлнүүдые унтаруулхыень дурадхабал — арсагты.

## 3-дахи алхам. «Хаана хадагалха» гэһэн асуудал унтараагты

Үгы һаа браузер файл бүхэнэй тухай асууха, тэдэнэр мянгаад байжа болохо.

- **Chrome:** `chrome://settings/downloads` нээгээд, **«Перед скачиванием спрашивать, куда сохранить файл»** (хадагалха газараа үргэлжэ асууха) гэһые унтараагты.
  ![Һэлгүүр унтараатай байха ёһотой](../docs/guide-downloads.png)
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → **«Всегда спрашивать, куда сохранять файлы»** тэмдэгые абагты.
- **Бусад браузернууд:** тохируулгануудай буулгалгын хэһэгтэ файл бүхэниие хаана хадагалха тухай асуудал унтараагты.

## 4-дэхи алхам. Файлнуудые буулгагты

1. [disk.yandex.ru](https://disk.yandex.ru) нээгээд, өөрынгөө аккаунт руу ороогты. Диск урид нээлттэй байгаа һаа — хуудаһа шэнэлэгты (F5).
2. Доодо баруун булангта хүхэ **«Бүхы Диск буулгаха»** товшуур бии болохо. Папка соо тэрэнэй нэрэ «Папка буулгаха», харин файлнуудые тэмдэглэбэл — «Тэмдэглэгшые буулгаха».
   ![Диск дээрэхи хүхэ товшуур](../docs/guide-button.png)
3. Тэрэн дээрэ дарагты. Сонхо нээгдэхэ:
   - **«Юу буулгаха»** — бүхы Диск, энэ папка, тэмдэглэгшэ али жагсаалтаһаа «Файлнууд болон папкануудые шэлэхэ…»;
   - **«Ямар файлнууд»** — бүгэдэ али «Хэрэгтэй түрэлнүүд лэ» (жэшээлбэл, гансал фото болон видео);
   - **«Хаана хадагалха»** — компьютер руу Диск дээрэхи шэнги файлнуудаар, нэгэ ZIP-архиваар али ондоо үүлэн руу.
4. **«Буулгалга эхилхэ»** дараад, хүлеэгты. Сонходо хэды буулгагдаһан харагдана.

![Үргэдхэлэй сонхо](../docs/guide-window.png)

*Зурагта — ородой интерфейс. Хэлэ сонхын дээдэ мүртэ шэлэгдэнэ: 23 хэлэн бии, буряадаар мүн.*

**Буулгалга ябажа байхада** Дискын вкладка жэжэрүүлжэ болоно, харин тэрэниие **бү хаагты**. Вкладка хаагдаа али компьютер унтараа һаа — Дискые дахин нээгээд, «Үргэлжэлүүлхэ» дарагты. Буулгагдаһан файлнууд дахин буулгагдахагүй.

**Файлнууд хаана байнаб:** «Загрузки» → «Яндекс Диск», Диск дээрэхи шэнги папкануудаар.

## Ямар нэгэн юумэн бүтөөгүй һаа

| Юун харагданаб | Юу хэхэб |
| --- | --- |
| Хүхэ товшуур үгы | Дискын хуудаһа шэнэлэгты (F5). `chrome://extensions` соо үргэдхэл ногоогдоһоние шалгагты. |
| Браузер файл бүхэниие хаана хадагалхые асууна | 3-дахи алхамые хээд, «Үргэлжэлүүлхэ» дарагты. |
| Зарим файлнууд «Бүтөөгүй» | Яндексын серверүүд мүнөө бүгэдыень үгэнэгүй. Нэгэ-хоёр сагай һүүлдэ «Бүтөөгүйнүүдые дахин хэхэ» дарагты. Иимэ файлнуудай жагсаалта «Отчёт (CSV)» товшуур хадагална. |
| Компьютер дээрэ һуури бага | Хэһэгүүдтэ хубаагдаһан «ZIP-архив», үүлэн руу шэлжүүлгэ али браузерай тохируулгануудта гадаада дискые буулгалгын папка болгон шэлэгты. |
| «Яндекс шалгалта гарахые гуйна» | «Шалгалта гараха» дараад, робот бэшэ гэжэ баталагты, тиигээд «Үргэлжэлүүлхэ» дарагты. |
| Фотогой нэрэ соо «(урдаһаа харалга)» бии | Оригинал үгтөөгүй, жэжэрүүлэгдэһэн хуулбари хадагалагдаа. Һүүлдэнь «Урдаһаа харалгын орондо оригиналнуудые дахин оролдохо» дарагты. |

## Энэ аюулгүй гү?

- Үргэдхэл гансал Яндекс Дискын сайт дээрэ, гансал таанай браузер соо ажалладаг. Яндексын нюуса үгэ асуудаггүй. Таанай файлнууд хаашаашье эльгээгдэдэггүй — өөһэдөө холбоһон үүлэнһээ бэшэ.
- Энэ Яндексын программа бэшэ, нээлттэй кодтой бээе даанги түлбэригүй проект.

## Яажа усадхаха али шэнэлхэ бэ

- **Усадхаха:** `chrome://extensions` → үргэдхэлэй хажуудахи «Удалить». Буулгагдаһан файлнууд үлэхэ.
- **Шэнэлхэ:** архивые дахин буулгагты (1-дэхи алхам), хуушан папка дээгүүр файлнуудые һэлгэжэ гаргагты, тиигээд `chrome://extensions` соо үргэдхэлэй хажуудахи дугы стрелкэ дээрэ дарагты.
