# Ինչպես ներբեռնել ամեն ինչ Յանդեքս Դիսկից

Պարզ ուղեցույց։ Կտևի մոտ հինգ րոպե։

*Թարգմանված է ռուսերենից. ուղղումները ողջունելի են [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues)-ում։*

**Ինչ է պատահել։** 2026 թվականի հոկտեմբերի 11-ից Յանդեքս Դիսկի կայքում հնարավոր չէ միանգամից ներբեռնել թղթապանակ, մի քանի ֆայլ կամ ամբողջ Դիսկը՝ միայն մեկ առ մեկ։ «Ներբեռնել ամբողջը Յանդեքս Դիսկից» անվճար ընդլայնումը վերադարձնում է «Ներբեռնել» կոճակը. այն ինքն է ներբեռնում ֆայլերը մեկ առ մեկ և դասավորում նույն թղթապանակներում, ինչ Դիսկում։

**Ինչ է պետք․**

- համակարգիչ կամ նոութբուք (Windows, macOS կամ Linux),
- Google Chrome կամ Յանդեքս Բրաուզեր (կհամապատասխանեն նաև Edge, Opera, Brave, Vivaldi),
- ազատ տեղ համակարգչում՝ մոտավորապես այնքան, որքան զբաղված է Դիսկում։

Հեռախոսում չի աշխատում. բջջային բրաուզերներում նման ընդլայնում չի տեղադրվում։ Պետք է համակարգիչ։

## Քայլ 1. Ներբեռնեք ընդլայնումը

1. Սեղմեք՝ **[ներբեռնել yandex-disk-download-all.zip](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**։ Ֆայլը կպահվի «Ներբեռնումներ» թղթապանակում։
2. Բացեք արխիվը.
   - **Windows՝** մկնիկի աջ կոճակով սեղմեք ֆայլի վրա → «Արտահանել բոլորը…» («Извлечь все…») → «Արտահանել»,
   - **macOS՝** կրկնակի սեղմեք ֆայլի վրա։
3. Կհայտնվի `yandex-disk-download-all` թղթապանակը։ Տեղափոխեք այն այնպիսի տեղ, որտեղ չի խանգարի, օրինակ՝ «Փաստաթղթեր»։ Հետո մի՛ ջնջեք այն. բրաուզերը ընդլայնումը վերցնում է այս թղթապանակից։

## Քայլ 2. Տեղադրեք ընդլայնումը բրաուզերում

**Google Chrome**

1. Հասցեի տողում մուտքագրեք `chrome://extensions` և սեղմեք Enter։
2. Վերևի աջ անկյունում միացրեք **«Մշակողի ռեժիմ»** (անգլերեն՝ Developer mode, ռուսերեն՝ «Режим разработчика») փոխանջատիչը։
3. Վերևի ձախ անկյունում սեղմեք առաջին կոճակը՝ **«Բեռնել չփաթեթավորվածը»** (անգլերեն՝ Load unpacked, ռուսերեն՝ «Загрузить распакованное расширение»)։
4. Ընտրեք `yandex-disk-download-all` թղթապանակը (այն, որում գտնվում է `manifest.json` ֆայլը)։
5. Ցանկում կհայտնվի ընդլայնումը։ Պատրաստ է։

**Յանդեքս Բրաուզեր**՝ նույնը, միայն հասցեն է `browser://extensions`։

**Edge, Opera, Brave, Vivaldi**՝ հասցեները `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, այնուհետև նույնը՝ «Մշակողի ռեժիմ» → «Բեռնել չփաթեթավորվածը»։

> «Մշակողի ռեժիմը» նորմալ է. այսպես են տեղադրվում խանութից դուրս ընդլայնումները։ Ընդլայնումն անվճար է, կոդը՝ բաց։ Եթե բրաուզերը գործարկման ժամանակ առաջարկի անջատել նման ընդլայնումները՝ հրաժարվեք։

## Քայլ 3. Անջատեք «որտեղ պահպանել» հարցը

Այլապես բրաուզերը կհարցնի յուրաքանչյուր ֆայլի մասին, իսկ դրանք կարող են հազարներ լինել։

- **Chrome՝** բացեք `chrome://settings/downloads` և անջատեք **«Հարցնել, թե որտեղ պահել յուրաքանչյուր ֆայլ»** (անգլերեն՝ Ask where to save each file before downloading, ռուսերեն՝ «Всегда указывать место для скачивания»)։
- **Յանդեքս Բրաուզեր՝** «Настройки» → «Инструменты» → «Загруженные файлы» → հանեք **«Всегда спрашивать, куда сохранять файлы»** նշիչը։
- **Այլ բրաուզերներ՝** կարգավորումների ներբեռնումների բաժնում անջատեք յուրաքանչյուր ֆայլի պահպանման տեղի մասին հարցը։

## Քայլ 4. Ներբեռնեք ֆայլերը

1. Բացեք [disk.yandex.ru](https://disk.yandex.ru)-ն և մուտք գործեք ձեր հաշիվ։ Եթե Դիսկն արդեն բաց էր՝ թարմացրեք էջը (F5)։
2. Ներքևի աջ անկյունում կհայտնվի կապույտ **«Ներբեռնել ամբողջ Դիսկը»** կոճակը։ Թղթապանակի ներսում այն կոչվում է «Ներբեռնել թղթապանակը», իսկ եթե ֆայլեր ընտրեք՝ «Ներբեռնել ընտրվածը»։
3. Սեղմեք այն։ Կբացվի պատուհան.
   - **«Ինչ ներբեռնել»**՝ ամբողջ Դիսկը, այս թղթապանակը, ընտրվածը կամ ցանկից «Ընտրել ֆայլեր և թղթապանակներ…»,
   - **«Որ ֆայլերը»**՝ բոլորը կամ «Միայն անհրաժեշտ տեսակները» (օրինակ՝ միայն լուսանկարներ և տեսանյութեր),
   - **«Որտեղ պահպանել»**՝ համակարգչում ֆայլերով, ինչպես Դիսկում, մեկ ZIP արխիվով կամ այլ ամպում։
4. Սեղմեք **«Սկսել ներբեռնումը»** և սպասեք։ Պատուհանում երևում է, թե որքան է արդեն ներբեռնվել։

![Ընդլայնման պատուհանը](../docs/setup.png)

*Նկարում ռուսերեն միջերեսն է։ Լեզուն ընտրվում է պատուհանի վերին տողում. կա 23 լեզու, այդ թվում՝ հայերեն։*

**Մինչ ներբեռնումն ընթանում է**, Դիսկի ներդիրը կարելի է ծալել, բայց **մի՛ փակեք** այն։ Եթե ներդիրը փակվել է կամ համակարգիչն անջատվել է՝ նորից բացեք Դիսկը և սեղմեք «Շարունակել»։ Արդեն ներբեռնվածը կրկին չի ներբեռնվում։

**Որտեղ են ֆայլերը՝** «Ներբեռնումներ» → «Yandex Disk», նույն թղթապանակներով, ինչ Դիսկում։

| Բրաուզերը հարցնում է, թե որտեղ պահպանել յուրաքանչյուր ֆայլ | Կատարեք քայլ 3-ը և սեղմեք «Շարունակել»։ |

| Համակարգչում քիչ տեղ կա | Ընտրեք մասերով «ZIP արխիվ», տեղափոխում ամպ կամ բրաուզերի կարգավորումներում արտաքին սկավառակը որպես ներբեռնումների թղթապանակ։ |

| Լուսանկարի անվան մեջ կա «(նախադիտում)» | Բնօրինակը չտրվեց, պահպանվեց փոքրացված պատճենը։ Ավելի ուշ սեղմեք «Նախադիտումների փոխարեն կրկին փորձել բնօրինակները»։ |

## Արդյո՞ք սա անվտանգ է

- Ընդլայնումն աշխատում է միայն Յանդեքս Դիսկի կայքում և միայն ձեր բրաուզերում։ Այն չի հարցնում Յանդեքսի գաղտնաբառը։ Ձեր ֆայլերը ոչ մի տեղ չեն ուղարկվում, բացի այն ամպից, որը դուք ինքներդ կմիացնեք։
- Սա Յանդեքսի ծրագիր չէ, այլ բաց կոդով անկախ անվճար նախագիծ։

## Ինչպես հեռացնել կամ թարմացնել

- **Հեռացնել՝** `chrome://extensions` → ընդլայնման կողքին «Հեռացնել»։ Ներբեռնված ֆայլերը կմնան։
- **Թարմացնել՝** նորից ներբեռնեք արխիվը (քայլ 1), բացեք այն հին թղթապանակի վրա՝ փոխարինելով ֆայլերը, ապա `chrome://extensions`-ում սեղմեք ընդլայնման կողքի կլոր սլաքը։
