# Яндекс Дисктен баарын кантип жүктөп алса болот

Жөнөкөй нускама. Болжол менен беш мүнөт талап кылынат.

*Орус тилинен которулган — оңдоолорду [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) аркылуу жиберсеңиз, кубанабыз.*

**Эмне болду.** 2026-жылдын 11-октябрынан тартып Яндекс Диск сайтында папканы, бир нече файлды же бүт Дискти бир жолу жүктөп алууга болбойт — бир-бирден гана. «Яндекс Дисктен баарын жүктөп алуу» деген акысыз браузер кеңейтүүсү «Жүктөп алуу» баскычын кайтарат: ал файлдарды бир-бирден өзү жүктөп, Дисктегидей папкаларга жайгаштырат.

**Эмне керек:**

- компьютер же ноутбук (Windows, macOS же Linux);
- Google Chrome же Яндекс Браузер (Edge, Opera, Brave, Vivaldi да жарайт);
- компьютерде бош орун — болжол менен Дискте канча орун ээленсе, ошончо.

Телефондо иштебейт: мобилдик браузерлерге мындай кеңейтүү орнотулбайт. Компьютер керек.

## 1-кадам. Кеңейтүүнү жүктөп алыңыз

1. Басыңыз: **[yandex-disk-download-all.zip жүктөп алуу](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл «Жүктөлүп алынгандар» («Загрузки») папкасына сакталат.
2. Аны архивден чыгарыңыз:
   - **Windows:** файлды чычкандын оң баскычы менен басыңыз → «Баарын чыгаруу…» («Извлечь все…») → «Чыгаруу»;
   - **macOS:** файлды эки жолу басыңыз.
3. `yandex-disk-download-all` папкасы пайда болот. Аны тоскоол болбой турган жерге, мисалы «Документтер» папкасына көчүрүңүз. Кийин өчүрбөңүз: браузер кеңейтүүнү ушул папкадан алат.

## 2-кадам. Кеңейтүүнү браузерге орнотуңуз

**Google Chrome**

1. Дарек сабына `chrome://extensions` деп жазып, Enter басыңыз.
2. Жогорку оң бурчта **«Иштеп чыгуучу режими»** (орусча «Режим разработчика») которгучун күйгүзүңүз.
3. Жогорку сол бурчтагы биринчи баскычты басыңыз — **«Таңгагы ачылган кеңейтүүнү жүктөө»** (орусча «Загрузить распакованное расширение»).
4. `yandex-disk-download-all` папкасын тандаңыз (ичинде `manifest.json` файлы жаткан папка).
5. Тизмеде «Яндекс Дисктен баарын жүктөп алуу» пайда болот. Даяр.

**Яндекс Браузер** — дал ошондой, дареги гана `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — даректери `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, андан ары дал ошондой: «Иштеп чыгуучу режими» → «Таңгагы ачылган кеңейтүүнү жүктөө».

> «Иштеп чыгуучу режими» — бул кадимки нерсе: дүкөндөн эмес кеңейтүүлөр ушундай орнотулат. Кеңейтүү акысыз, коду ачык. Эгер браузер иштеп баштаганда мындай кеңейтүүлөрдү өчүрүүнү сунуштаса — баш тартыңыз.

## 3-кадам. «Кайда сактоо» суроосун өчүрүңүз

Болбосо браузер ар бир файл тууралуу сурайт, а алар миңдеген болушу мүмкүн.

- **Chrome:** `chrome://settings/downloads` ачып, **«Ар бир файлды кайда сактоону суроо»** дегенди өчүрүңүз (орусча «Перед скачиванием спрашивать, куда сохранить файл»).
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → **«Всегда спрашивать, куда сохранять файлы»** белгисин алып салыңыз.
- **Башка браузерлер:** жөндөөлөрдүн жүктөөлөр бөлүмүндө ар бир файлды кайда сактоо тууралуу суроону өчүрүңүз.

## 4-кадам. Файлдарды жүктөп алыңыз

1. [disk.yandex.ru](https://disk.yandex.ru) ачып, аккаунтуңузга кириңиз. Диск мурунтан ачык болсо — баракты жаңыртыңыз (F5).
2. Төмөнкү оң бурчта көк **«Бүт Дискти жүктөп алуу»** баскычы пайда болот. Папканын ичинде ал «Папканы жүктөп алуу» деп аталат, ал эми файлдарды белгилесеңиз — «Белгиленгенди жүктөп алуу».
3. Аны басыңыз. Терезе ачылат:
   - **«Эмнени жүктөп алуу»** — бүт Диск, ушул папка, белгиленгендер же тизмеден «Файлдарды жана папкаларды тандоо…»;
   - **«Кандай файлдар»** — баары же «Керектүү түрлөр гана» (мисалы, сүрөт жана видео гана);
   - **«Кайда сактоо»** — компьютерге Дисктегидей файлдар түрүндө, бир ZIP-архив түрүндө же башка булутка.
4. **«Жүктөөнү баштоо»** баскычын басып, күтүңүз. Терезеде канчасы жүктөлгөнү көрүнөт.

![Кеңейтүүнүн терезеси](../docs/guide-window.png)

*Сүрөттө — орусча интерфейс. Тил терезенин жогорку сабында тандалат: 23 тил бар, кыргызча да бар.*

**Жүктөө жүрүп жатканда** Диск өтмөгүн кичирейтип коюуга болот, бирок аны **жаппаңыз**. Өтмөк жабылып калса же компьютер өчүп калса — Дискти кайра ачып, «Улантуу» баскычын басыңыз. Жүктөлүп бүткөн файлдар кайра жүктөлбөйт.

**Файлдар кайда:** «Жүктөлүп алынгандар» → «Яндекс Диск», Дисктегидей папкалар боюнча.

## Бир нерсе болбой калса

| Эмне көрүнөт | Эмне кылуу керек |
| --- | --- |
| Көк баскыч жок | Диск барагын жаңыртыңыз (F5). `chrome://extensions` ичинде кеңейтүү күйгүзүлгөнүн текшериңиз. |
| Браузер ар бир файлды кайда сактоону сурайт | 3-кадамды аткарып, «Улантуу» басыңыз. |
| Айрым файлдар «Ийгиликсиз» | Яндекс серверлери азыр баарын бербей жатат. Бир-эки сааттан кийин «Ийгиликсиздерин кайталоо» басыңыз. Мындай файлдардын тизмесин «Отчёт (CSV)» баскычы сактайт. |
| Компьютерде орун аз | Бөлүктөргө бөлүнгөн «ZIP-архив», булутка көчүрүү же браузердин жөндөөлөрүндө тышкы дискти жүктөөлөр папкасы катары тандаңыз. |
| «Яндекс текшерүүдөн өтүүнү сурап жатат» | «Текшерүүдөн өтүү» басып, робот эмес экениңизди тастыктаңыз, андан кийин «Улантуу» басыңыз. |
| Сүрөттүн атында «(алдын ала көрүнүш)» бар | Түп нуска берилген жок, кичирейтилген көчүрмөсү сакталды. Кийинчерээк «Алдын ала көрүнүштүн ордуна түп нускаларды кайра байкап көрүү» басыңыз. |

## Бул коопсузбу?

- Кеңейтүү Яндекс Диск сайтында гана жана сиздин браузериңизде гана иштейт. Яндекстин сырсөзүн сурабайт. Файлдарыңыз эч жакка жөнөтүлбөйт — өзүңүз туташтырган булуттан башка.
- Бул Яндекстин программасы эмес, коду ачык көз карандысыз акысыз долбоор.

## Кантип өчүрүү же жаңыртуу керек

- **Өчүрүү:** `chrome://extensions` → кеңейтүүнүн жанындагы «Алып салуу». Жүктөлгөн файлдар калат.
- **Жаңыртуу:** архивди кайра жүктөп алыңыз (1-кадам), эски папканын үстүнө файлдарды алмаштырып чыгарыңыз, андан кийин `chrome://extensions` ичинде кеңейтүүнүн жанындагы тегерек жебени басыңыз.
