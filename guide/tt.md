# Яндекс Дисктан барысын да ничек йөкләп алырга

Гади күрсәтмә. Якынча биш минут вакыт ала.

*Рус теленнән тәрҗемә — төзәтмәләрне [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) аша җибәрсәгез, рәхмәтле булырбыз.*

**Нәрсә булды.** 2026 елның 11 октябреннән Яндекс Диск сайтында папканы, берничә файлны яки бөтен Дискны берьюлы йөкләп алып булмый — бары тик берәмләп кенә. «Яндекс Дисктан барысын да йөкләп алу» дигән бушлай браузер киңәйтмәсе «Йөкләп алу» төймәсен кире кайтара: ул файлларны берәмләп үзе йөкли һәм Дисктагы кебек папкаларга урнаштыра.

**Нәрсә кирәк:**

- компьютер яки ноутбук (Windows, macOS яки Linux);
- Google Chrome яки Яндекс Браузер (Edge, Opera, Brave, Vivaldi да ярый);
- компьютерда буш урын — якынча Дискта күпме урын алынган, шулкадәр.

Телефонда эшләми: мобиль браузерларга мондый киңәйтмә куеп булмый. Компьютер кирәк.

## 1 нче адым. Киңәйтмәне йөкләп алыгыз

1. Басыгыз: **[yandex-disk-download-all.zip йөкләп алу](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл «Загрузки» папкасына сакланачак.
2. Аны архивтан чыгарыгыз:
   - **Windows:** тычканның уң төймәсе белән файлга басыгыз → «Извлечь все…» (барысын да чыгару) → «Извлечь»;
   - **macOS:** файлга ике тапкыр басыгыз.
3. `yandex-disk-download-all` папкасы барлыкка килә. Аны комачауламаслык урынга, мәсәлән «Документы» папкасына күчерегез. Соңыннан бетермәгез: браузер киңәйтмәне шушы папкадан ала.

## 2 нче адым. Киңәйтмәне браузерга куегыз

**Google Chrome**

1. Адрес юлына `chrome://extensions` языгыз һәм Enter басыгыз.
2. Өске уң почмакта **«Режим разработчика»** (эшләүче режимы) күчергечен кабызыгыз.
3. Өске сул почмактагы беренче төймәгә басыгыз — **«Загрузить распакованное расширение»** (ачылган киңәйтмәне йөкләү).
   ![«Режим разработчика» (1) һәм «Загрузить распакованное расширение» (2) кайда](../docs/guide-extensions.png)
4. `yandex-disk-download-all` папкасын сайлагыз (эчендә `manifest.json` файлы булган папка).
5. Исемлектә «Скачать всё с Яндекс Диска» киңәйтмәсе барлыкка килә. Әзер.

**Яндекс Браузер** — нәкъ шулай ук, адресы гына `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — адреслар `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, аннары нәкъ шулай ук: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — бу гадәти хәл: кибеттән булмаган киңәйтмәләр шулай куела. Киңәйтмә бушлай, аның коды ачык. Әгәр браузер эшли башлаганда мондый киңәйтмәләрне сүндерергә тәкъдим итсә — баш тартыгыз.

## 3 нче адым. «Кая сакларга» соравын сүндерегез

Югыйсә браузер һәр файл турында сораячак, ә алар меңләгән булырга мөмкин.

- **Chrome:** `chrome://settings/downloads` ачыгыз һәм **«Перед скачиванием спрашивать, куда сохранить файл»** (һәрвакыт саклау урынын сорау) дигәнне сүндерегез.
  ![Күчергеч сүндерелгән булырга тиеш](../docs/guide-downloads.png)
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → **«Всегда спрашивать, куда сохранять файлы»** билгесен алыгыз.
- **Башка браузерлар:** көйләүләрнең йөкләүләр бүлегендә һәр файлны кая саклау турындагы сорауны сүндерегез.

## 4 нче адым. Файлларны йөкләп алыгыз

1. [disk.yandex.ru](https://disk.yandex.ru) ачыгыз һәм аккаунтыгызга керегез. Диск инде ачык булса — битне яңартыгыз (F5).
2. Аскы уң почмакта зәңгәр **«Бөтен Дискны йөкләп алу»** төймәсе барлыкка килә. Папка эчендә ул «Папканы йөкләп алу» дип атала, ә файлларны билгеләсәгез — «Билгеләнгәнне йөкләп алу».
   ![Дисктагы зәңгәр төймә](../docs/guide-button.png)
3. Аңа басыгыз. Тәрәзә ачыла:
   - **«Нәрсәне йөкләп алырга»** — бөтен Диск, шушы папка, билгеләнгәннәр яки исемлектән «Файлларны һәм папкаларны сайлау…»;
   - **«Нинди файллар»** — барысы да яки «Кирәкле төрләр генә» (мәсәлән, фото һәм видео гына);
   - **«Кая сакларга»** — компьютерга Дисктагы кебек файллар итеп, бер ZIP-архив итеп яки башка болытка.
4. **«Йөкләүне башлау»** төймәсенә басыгыз һәм көтегез. Тәрәзәдә күпмесе йөкләнгәне күренә.

![Киңәйтмә тәрәзәсе](../docs/guide-window.png)

*Рәсемдә — рус телендәге интерфейс. Тел тәрәзәнең өске юлында сайлана: 23 тел бар, татарча да бар.*

**Йөкләү барганда** Диск кыстыргычын җыеп куярга була, ләкин аны **ябмагыз**. Кыстыргыч ябылса яки компьютер сүнсә — Дискны яңадан ачыгыз һәм «Дәвам итү» төймәсенә басыгыз. Инде йөкләнгән файллар кабат йөкләнми.

**Файллар кайда:** «Загрузки» → «Яндекс Диск», Дисктагы кебек папкалар буенча.

## Берәр нәрсә барып чыкмаса

| Нәрсә күренә | Нишләргә |
| --- | --- |
| Зәңгәр төймә юк | Диск битен яңартыгыз (F5). `chrome://extensions` эчендә киңәйтмә кабызылганын тикшерегез. |
| Браузер һәр файлны кая сакларга икәнен сорый | 3 нче адымны башкарыгыз һәм «Дәвам итү» басыгыз. |
| Кайбер файллар «Барып чыкмады» | Яндекс серверлары хәзер барысын да бирми. Бер-ике сәгатьтән «Барып чыкмаганнарны кабатлау» басыгыз. Андый файллар исемлеген «Хисап (CSV)» төймәсе саклый. |
| Компьютерда урын аз | Өлешләргә бүленгән «ZIP-архив», болытка күчерү яки браузер көйләүләрендә тышкы дискны йөкләүләр папкасы итеп сайлагыз. |
| «Яндекс тикшерүне узуны сорый» | «Тикшерүне узу» басыгыз, робот түгеллегегезне раслагыз, аннары «Дәвам итү» басыгыз. |
| Фото исемендә «(алдан карау)» бар | Төп нөсхә бирелмәде, кечерәйтелгән күчермәсе сакланды. Соңрак «Алдан карау урынына төп нөсхәләрне кабат тырышып карау» басыгыз. |

## Бу куркынычсызмы?

- Киңәйтмә Яндекс Диск сайтында гына һәм сезнең браузерда гына эшли. Яндекс серсүзен сорамый. Файлларыгыз беркая да җибәрелми — үзегез тоташтырган болыттан тыш.
- Бу Яндекс программасы түгел, ә коды ачык бәйсез бушлай проект.

## Ничек бетерергә яки яңартырга

- **Бетерү:** `chrome://extensions` → киңәйтмә янындагы «Удалить». Йөкләнгән файллар кала.
- **Яңарту:** архивны яңадан йөкләп алыгыз (1 нче адым), иске папка өстенә файлларны алыштырып чыгарыгыз, аннары `chrome://extensions` эчендә киңәйтмә янындагы түгәрәк укка басыгыз.
