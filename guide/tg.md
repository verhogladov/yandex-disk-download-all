# Чӣ тавр ҳама чизро аз Яндекс Диск боргирӣ кардан мумкин аст

Дастури содда. Тақрибан панҷ дақиқа вақт мегирад.

*Аз забони русӣ тарҷума шудааст — ислоҳҳоро дар [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues) фиристед, хурсанд мешавем.*

**Чӣ шуд.** Аз 11 октябри соли 2026 дар сайти Яндекс Диск ҷузвдон, якчанд файл ё тамоми Дискро якбора боргирӣ кардан мумкин нест — танҳо як-як. Васеъкунандаи ройгони браузер «Боргирии ҳама аз Яндекс Диск» тугмаи «Боргирӣ»-ро бармегардонад: он файлҳоро худаш як-як боргирӣ мекунад ва ба ҳамон ҷузвдонҳое, ки дар Диск ҳастанд, ҷойгир мекунад.

**Чӣ лозим аст:**

- компютер ё ноутбук (Windows, macOS ё Linux);
- браузери Google Chrome ё Яндекс Браузер (Edge, Opera, Brave, Vivaldi ҳам мувофиқанд);
- ҷои холӣ дар компютер — тақрибан ҳамон қадар, ки дар Диск банд аст.

Дар телефон кор намекунад: ба браузерҳои мобилӣ чунин васеъкунандаро насб кардан мумкин нест. Компютер лозим аст.

## Қадами 1. Васеъкунандаро боргирӣ кунед

1. Пахш кунед: **[боргирии yandex-disk-download-all.zip](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. Файл ба ҷузвдони «Загрузки» нигоҳ дошта мешавад.
2. Онро аз бойгонӣ бароред:
   - **Windows:** бо тугмаи рости муш файлро пахш кунед → «Извлечь все…» → «Извлечь»;
   - **macOS:** файлро ду бор пахш кунед.
3. Ҷузвдони `yandex-disk-download-all` пайдо мешавад. Онро ба ҷое гузоред, ки халал намерасонад, масалан ба «Документы». Баъдтар нест накунед: браузер васеъкунандаро аз ҳамин ҷузвдон мегирад.

## Қадами 2. Васеъкунандаро ба браузер насб кунед

**Google Chrome**

1. Ба сатри суроға `chrome://extensions` нависед ва Enter-ро пахш кунед.
2. Дар кунҷи болои рост калиди **«Режим разработчика»** (ҳолати таҳиягар)-ро фаъол кунед.
3. Дар кунҷи болои чап тугмаи якумро пахш кунед — **«Загрузить распакованное расширение»** (боркунии васеъкунандаи кушодашуда).
   ![«Режим разработчика» (1) ва «Загрузить распакованное расширение» (2) дар куҷоянд](../docs/guide-extensions.png)
4. Ҷузвдони `yandex-disk-download-all`-ро интихоб кунед (ҳамон ҷузвдоне, ки дар он файли `manifest.json` ҳаст).
5. Дар рӯйхат «Скачать всё с Яндекс Диска» пайдо мешавад. Тайёр.

**Яндекс Браузер** — ҳамин тавр, танҳо суроға `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — суроғаҳо `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, минбаъд ҳамин тавр: «Режим разработчика» → «Загрузить распакованное».

> «Режим разработчика» — ин муқаррарӣ аст: васеъкунандаҳое, ки аз мағоза нестанд, ҳамин тавр насб мешаванд. Васеъкунанда ройгон аст, рамзи он кушода аст. Агар браузер ҳангоми оғоз пешниҳод кунад, ки чунин васеъкунандаҳоро хомӯш кунед — рад кунед.

## Қадами 3. Саволи «куҷо нигоҳ доштан»-ро хомӯш кунед

Вагарна браузер дар бораи ҳар як файл мепурсад, онҳо бошад метавонанд ҳазорҳо бошанд.

- **Chrome:** `chrome://settings/downloads`-ро кушоед ва **«Перед скачиванием спрашивать, куда сохранить файл»**-ро хомӯш кунед.
  ![Калид бояд хомӯш бошад](../docs/guide-downloads.png)
- **Яндекс Браузер:** «Настройки» → «Инструменты» → «Загруженные файлы» → аломати **«Всегда спрашивать, куда сохранять файлы»**-ро бардоред.
- **Браузерҳои дигар:** дар танзимот, дар қисми боргириҳо, саволро дар бораи ҷои нигоҳдории ҳар як файл хомӯш кунед.

## Қадами 4. Файлҳоро боргирӣ кунед

1. [disk.yandex.ru](https://disk.yandex.ru)-ро кушоед ва ба ҳисоби худ ворид шавед. Агар Диск аллакай кушода бошад — саҳифаро навсозӣ кунед (F5).
2. Дар кунҷи поёни рост тугмаи кабуди **«Боргирии тамоми Диск»** пайдо мешавад. Дар дохили ҷузвдон он «Боргирии ҷузвдон» ном дорад, агар файлҳоро интихоб кунед — «Боргирии интихобшуда».
   ![Тугмаи кабуд дар Диск](../docs/guide-button.png)
3. Онро пахш кунед. Равзана кушода мешавад:
   - **«Чиро боргирӣ кардан»** — тамоми Диск, ҳамин ҷузвдон, интихобшуда ё аз рӯйхат «Интихоби файлҳо ва ҷузвдонҳо…»;
   - **«Кадом файлҳо»** — ҳама ё «Танҳо навъҳои лозимӣ» (масалан, танҳо аксҳо ва видео);
   - **«Куҷо нигоҳ доштан»** — ба компютер ҳамчун файлҳо, мисли дар Диск, ҳамчун як бойгонии ZIP ё ба абри дигар.
4. **«Оғози боргирӣ»**-ро пахш кунед ва интизор шавед. Дар равзана дида мешавад, ки чӣ қадар боргирӣ шуд.

![Равзанаи васеъкунанда](../docs/guide-window.png)

*Дар расм — интерфейси русӣ. Забон дар сатри болоии равзана интихоб мешавад: 23 забон ҳаст, тоҷикӣ ҳам.*

**Ҳангоми боргирӣ** варақаи Дискро печондан мумкин аст, вале онро **напӯшед**. Агар варақа пӯшида шуд ё компютер хомӯш шуд — Дискро дубора кушоед ва «Идома додан»-ро пахш кунед. Файлҳои аллакай боргиришуда дубора боргирӣ намешаванд.

**Файлҳо дар куҷоянд:** «Загрузки» → «Яндекс Диск», мувофиқи ҳамон ҷузвдонҳое, ки дар Диск ҳастанд.

## Агар чизе нашуд

| Чӣ дида мешавад | Чӣ бояд кард |
| --- | --- |
| Тугмаи кабуд нест | Саҳифаи Дискро навсозӣ кунед (F5). Дар `chrome://extensions` санҷед, ки васеъкунанда фаъол аст. |
| Браузер мепурсад, ки ҳар як файлро куҷо нигоҳ дорад | Қадами 3-ро иҷро кунед ва «Идома додан»-ро пахш кунед. |
| Баъзе файлҳо «Муяссар нашуд» | Серверҳои Яндекс ҳоло на ҳамаро медиҳанд. Пас аз як-ду соат «Такрори ноком»-ро пахш кунед. Рӯйхати чунин файлҳоро тугмаи «Ҳисобот (CSV)» нигоҳ медорад. |
| Дар компютер ҷой кам аст | «Бойгонии ZIP»-ро қисм-қисм, интиқол ба абр ё дар танзимоти браузер диски берунаро ҳамчун ҷузвдони боргириҳо интихоб кунед. |
| «Яндекс аз санҷиш гузаштанро хоҳиш мекунад» | «Аз санҷиш гузаштан»-ро пахш кунед, исбот кунед, ки робот нестед, баъд «Идома додан»-ро пахш кунед. |
| Дар номи акс «(пешнамоиш)» ҳаст | Асл дода нашуд, нусхаи хурдшуда нигоҳ дошта шуд. Баъдтар «Ба ҷои пешнамоиш аслҳоро боз кӯшиш кардан»-ро пахш кунед. |

## Ин бехатар аст?

- Васеъкунанда танҳо дар сайти Яндекс Диск ва танҳо дар браузери шумо кор мекунад. Пароли Яндексро намепурсад. Файлҳои шумо ба ҳеҷ ҷо фиристода намешаванд — ба ғайр аз абре, ки худатон пайваст мекунед.
- Ин барномаи Яндекс нест, балки лоиҳаи мустақили ройгон бо рамзи кушода аст.

## Чӣ тавр нест кардан ё навсозӣ кардан

- **Нест кардан:** `chrome://extensions` → «Удалить» дар назди васеъкунанда. Файлҳои боргиришуда мемонанд.
- **Навсозӣ:** бойгониро дубора боргирӣ кунед (қадами 1), болои ҷузвдони кӯҳна бо ивазкунии файлҳо бароред, баъд дар `chrome://extensions` тирчаи даврии назди васеъкунандаро пахш кунед.
