# როგორ ჩამოვტვირთოთ ყველაფერი იანდექს დისკიდან

მარტივი ინსტრუქცია. დაახლოებით ხუთ წუთს წაიღებს.

*თარგმნილია რუსულიდან — შესწორებები მისასალმებელია [GitHub](https://github.com/verhogladov/yandex-disk-download-all/issues)-ზე.*

**რა მოხდა.** 2026 წლის 11 ოქტომბრიდან იანდექს დისკის საიტზე შეუძლებელია საქაღალდის, რამდენიმე ფაილის ან მთელი დისკის ერთბაშად ჩამოტვირთვა — მხოლოდ თითო-თითოდ. ბრაუზერის უფასო გაფართოება „ყველაფრის ჩამოტვირთვა იანდექს დისკიდან“ აბრუნებს ღილაკს „ჩამოტვირთვა“: ის თავად ჩამოტვირთავს ფაილებს თითო-თითოდ და ალაგებს მათ იმავე საქაღალდეებში, როგორც დისკზეა.

**რა არის საჭირო:**

- კომპიუტერი ან ლეპტოპი (Windows, macOS ან Linux);
- Google Chrome ან იანდექს ბრაუზერი (გამოდგება Edge, Opera, Brave, Vivaldi-ც);
- თავისუფალი ადგილი კომპიუტერზე — დაახლოებით იმდენი, რამდენიც დისკზეა დაკავებული.

ტელეფონზე არ მუშაობს: მობილურ ბრაუზერებში ასეთი გაფართოება არ დგება. საჭიროა კომპიუტერი.

## ნაბიჯი 1. ჩამოტვირთეთ გაფართოება

1. დააჭირეთ: **[yandex-disk-download-all.zip-ის ჩამოტვირთვა](https://github.com/verhogladov/yandex-disk-download-all/releases/latest/download/yandex-disk-download-all.zip)**. ფაილი შეინახება საქაღალდეში „ჩამოტვირთვები“.
2. ამოაარქივეთ:
   - **Windows:** დააწკაპუნეთ ფაილზე თაგვის მარჯვენა ღილაკით → „ყველას ამოღება…“ („Извлечь все…“) → „ამოღება“;
   - **macOS:** ორჯერ დააწკაპუნეთ ფაილზე.
3. გაჩნდება საქაღალდე `yandex-disk-download-all`. გადაიტანეთ იქ, სადაც ხელს არ შეგიშლით, მაგალითად „დოკუმენტებში“. შემდეგ არ წაშალოთ: ბრაუზერი გაფართოებას ამ საქაღალდიდან იღებს.

## ნაბიჯი 2. დააყენეთ გაფართოება ბრაუზერში

**Google Chrome**

1. მისამართის ზოლში ჩაწერეთ `chrome://extensions` და დააჭირეთ Enter-ს.
2. ზედა მარჯვენა კუთხეში ჩართეთ გადამრთველი **„დეველოპერის რეჟიმი“** (ინგლისურად Developer mode, რუსულად «Режим разработчика»).
3. ზედა მარცხენა კუთხეში დააჭირეთ პირველ ღილაკს — **„გაუშლელის ჩატვირთვა“** (ინგლისურად Load unpacked, რუსულად «Загрузить распакованное расширение»).
4. აირჩიეთ საქაღალდე `yandex-disk-download-all` (ის, რომელშიც დევს ფაილი `manifest.json`).
5. სიაში გამოჩნდება გაფართოება. მზადაა.

**იანდექს ბრაუზერი** — ზუსტად ასევე, მხოლოდ მისამართია `browser://extensions`.

**Edge, Opera, Brave, Vivaldi** — მისამართები `edge://extensions`, `opera://extensions`, `brave://extensions`, `vivaldi://extensions`, შემდეგ ასევე: „დეველოპერის რეჟიმი“ → „გაუშლელის ჩატვირთვა“.

> „დეველოპერის რეჟიმი“ ნორმალურია: ასე დგება გაფართოებები, რომლებიც მაღაზიიდან არ არის. გაფართოება უფასოა, კოდი ღიაა. თუ ბრაუზერი გაშვებისას შემოგთავაზებთ ასეთი გაფართოებების გამორთვას — უარი თქვით.

## ნაბიჯი 3. გამორთეთ კითხვა „სად შევინახოთ“

თორემ ბრაუზერი ყოველ ფაილზე გკითხავთ, ისინი კი შეიძლება ათასობით იყოს.

- **Chrome:** გახსენით `chrome://settings/downloads` და გამორთეთ **„ჩამოტვირთვამდე იკითხეთ, სად შეინახოს თითოეული ფაილი“** (ინგლისურად Ask where to save each file before downloading, რუსულად «Перед скачиванием спрашивать, куда сохранить файл»).
- **იანდექს ბრაუზერი:** «Настройки» → «Инструменты» → «Загруженные файлы» → მოხსენით ნიშანი **«Всегда спрашивать, куда сохранять файлы»**.
- **სხვა ბრაუზერები:** პარამეტრებში, ჩამოტვირთვების განყოფილებაში, გამორთეთ კითხვა თითოეული ფაილის შენახვის ადგილზე.

## ნაბიჯი 4. ჩამოტვირთეთ ფაილები

1. გახსენით [disk.yandex.ru](https://disk.yandex.ru) და შედით თქვენს ანგარიშზე. თუ დისკი უკვე გახსნილი იყო — განაახლეთ გვერდი (F5).
2. ქვედა მარჯვენა კუთხეში გამოჩნდება ლურჯი ღილაკი **„მთელი დისკის ჩამოტვირთვა“**. საქაღალდის შიგნით მას ჰქვია „საქაღალდის ჩამოტვირთვა“, ხოლო თუ ფაილებს მონიშნავთ — „მონიშნულის ჩამოტვირთვა“.
3. დააჭირეთ მას. გაიხსნება ფანჯარა:
   - **„რა ჩამოიტვირთოს“** — მთელი დისკი, ეს საქაღალდე, მონიშნული ან სიიდან „ფაილებისა და საქაღალდეების არჩევა…“;
   - **„რომელი ფაილები“** — ყველა ან „მხოლოდ საჭირო ტიპები“ (მაგალითად, მხოლოდ ფოტოები და ვიდეოები);
   - **„სად შევინახოთ“** — კომპიუტერზე ფაილებად, როგორც დისკზეა, ერთ ZIP-არქივად ან სხვა ღრუბელში.
4. დააჭირეთ **„ჩამოტვირთვის დაწყება“**-ს და დაელოდეთ. ფანჯარაში ჩანს, რამდენი ჩამოიტვირთა უკვე.

![გაფართოების ფანჯარა](../docs/guide-window.png)

*სურათზე რუსული ინტერფეისია. ენა ირჩევა ფანჯრის ზედა ხაზში: 23 ენაა, მათ შორის ქართული.*

**სანამ ჩამოტვირთვა მიმდინარეობს**, დისკის ჩანართის ჩაკეცვა შეიძლება, მაგრამ **არ დახუროთ**. თუ ჩანართი დაიხურა ან კომპიუტერი გამოირთო — ხელახლა გახსენით დისკი და დააჭირეთ „გაგრძელება“-ს. უკვე ჩამოტვირთული თავიდან არ ჩამოიტვირთება.

**სად არის ფაილები:** „ჩამოტვირთვები“ → „Yandex Disk“, იმავე საქაღალდეებში, როგორც დისკზეა.

## ეს უსაფრთხოა?

- გაფართოება მუშაობს მხოლოდ იანდექს დისკის საიტზე და მხოლოდ თქვენს ბრაუზერში. ის არ გეკითხებათ იანდექსის პაროლს. თქვენი ფაილები არსად იგზავნება, გარდა იმ ღრუბლისა, რომელსაც თავად დააკავშირებთ.
- ეს არ არის იანდექსის პროგრამა, არამედ ღია კოდის დამოუკიდებელი უფასო პროექტი.

## როგორ წავშალოთ ან განვაახლოთ

- **წაშლა:** `chrome://extensions` → გაფართოებასთან „ამოშლა“. ჩამოტვირთული ფაილები დარჩება.
- **განახლება:** ხელახლა ჩამოტვირთეთ არქივი (ნაბიჯი 1), ამოაარქივეთ ძველი საქაღალდის თავზე ფაილების ჩანაცვლებით, შემდეგ `chrome://extensions`-ში დააჭირეთ გაფართოებასთან მრგვალ ისარს.
